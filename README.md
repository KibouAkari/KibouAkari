## About Me

I'm a **Computer Scientist apprentice** with a strong focus on **Cybersecurity, Software Engineering and Infrastructure**.

I enjoy understanding how systems work from the inside, building applications from the ground up, and exploring how systems can be secured, monitored and improved.

My main areas of interest include:

- Cybersecurity and security operations
- Network and web application security
- Fullstack development
- Linux and system administration
- Cloud and containerized environments
- Capture The Flag challenges and hands-on security labs
- Automation and infrastructure
- Exploring new technologies through personal projects

I work across **Windows, macOS and Linux**, giving me experience across different environments and system architectures.

> **Build it. Break it. Understand it. Secure it.**
